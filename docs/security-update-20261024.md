# Pillowの脆弱性対応（2026-10-24）

## 対応内容

`requirements.txt`のPillowを12.3.0から修正済みの13.0.0へ更新しました。
CVE-2026-112400は、不正なGIFのフレーム移動で発生する
`DecompressionBombError`を捕捉した後、同じ画像を使い続ける場合に
拒否された巨大な寸法が残り、メモリ枯渇につながる問題です。
現在のコードに該当するGIF処理は見当たりませんが、影響する依存バージョンを解消します。

## 検証

Windows / Python 3.14.6の独立した検証環境に全依存関係をインストールして確認しました。

- Botテスト: 80件、失敗なし、4件スキップ。
- 管理画面テスト: 17件成功。
- `pip check`: 依存関係の不整合なし。
- 日本語一覧画像のPNG出力・読み込み成功。
- 追加テストで、不正GIFを拒否した後も画像サイズが元の1×1のままであることを確認。
  手元の旧Pillow 11.1.0では同テストが失敗し、13.0.0では成功しました。
  テストは巨大画像の読み込みや再試行を行わず、拒否後の寸法だけを調べます。

## 稼働環境への反映と確認

反映時は既存イメージと変更対象ファイルをバックアップし、
更新済みrequirements.txtからBotイメージを再ビルドします。
新しいイメージ内でテストと依存関係の整合性を確認してから、Botだけを再起動します。
DBや管理画面の再起動、DBスキーマの変更は必要ありません。
再起動後にコンテナ内のPillowバージョン、Discord接続、DB同期を確認します。
実際の配置結果と使用イメージは対応PRのコメントへ記録します。
