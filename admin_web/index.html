          この統計について

          登録ワード数とランキングは削除済みを除く現在の登録データです。「参加ユーザー」はゲーム参加記録のユーザーを全サーバーで重複排除した数で、Discordサーバー全体のメンバー数ではありません。

          「導入サーバー」はDiscord APIで現在確認できるBot導入先の数です。「ゲーム稼働サーバー」はDBでゲーム開始中のサーバー数です。ランキングには退出済みサーバーの登録履歴も含みます。登録日時の履歴がないため、日別の新規登録数は表示していません。

          集計は最大60秒間キャッシュされます。ユーザー識別子は既存DBの保存形式に従います。
